CueFlow is a focused teleprompter for rehearsals, presentations, and recording.

Choose the installer for your computer:

- **Mac with Apple Silicon:** the `mac-arm64.dmg` file.
- **Mac with an Intel processor:** the `mac-x64.dmg` file.
- **Windows 10/11, 64-bit:** the `win-x64.exe` file.

On Mac, open the disk image and drag CueFlow into Applications. ZIP archives are also included. On Windows, run the installer and follow the setup steps.

These initial community builds are **unsigned and not notarized**. macOS Gatekeeper and Windows SmartScreen may display a warning or prevent launch. Review the source and the release's SHA256 checksums before installing. For a blocked Mac launch, use the app-specific approval in System Settings → Privacy & Security only if you trust this release. No global security settings need to be disabled.

Your scripts and settings are stored locally. Desktop and browser libraries are separate. Export scripts before clearing browser data or uninstalling the application.
